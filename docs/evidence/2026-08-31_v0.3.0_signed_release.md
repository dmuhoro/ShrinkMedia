# Evidence — v0.3.0 Signed Release APK (production keystore)

**Date:** 2026-08-31
**Claim:** ShrinkMedia ships a signed, R8-minified, installable v0.3.0 release APK
distributable via GitHub Releases sideload, signed with a production keystore.

## 1. Production keystore generated (outside the repo)

```
keytool -genkeypair -v \
  -keystore ~/.android/keystores/shrinkmedia-release.jks \
  -storepass <redacted> -alias shrinkmedia \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -dname "CN=ShrinkMedia, OU=ShrinkMedia, O=ShrinkMedia, L=Nairobi, ST=Nairobi, C=KE"
```

Observed output: `Generating 2,048 bit RSA key pair ... SHA256withRSA ... validity of 10,000 days`.
Keystore + passwords live under `~/.android/keystores/` — **outside the repo**, so they
are never committable. PKCS12: store password == key password.

Verified listing:

```

Creation date: Aug 31, 2026
Owner: CN=ShrinkMedia, OU=ShrinkMedia, O=ShrinkMedia, L=Nairobi, ST=Nairobi, C=KE
Valid from: Mon Aug 31 15:53:02 EAT 2026 until: Fri Jan 16 15:53:02 EAT 2054

```

`keystore.properties` (repo root, **gitignored** via `.gitignore` lines 25-28:
`keystore.properties`, `*.jks`, `*.keystore`) drives the release
`SigningConfig`. Build fails closed if it is absent.

## 2. Signed release APK built

```
$ ./gradlew :app:assembleRelease   ->  BUILD SUCCESSFUL
$ ls -la app/build/outputs/apk/release/app-release.apk

```

## 3. Version / package verified (aapt badging)

```
$ aapt dump badging app-release.apk
package: name='com.shrinkmedia.compressor' versionCode='3' versionName='0.3.0' ...
application-label:'Media Compressor'
```

## 4. Signature verified (apksigner)

```
$ apksigner verify --print-certs app-release.apk
Signer #1 certificate SHA-256 digest: 21569322706156fe02111cc5a8ce0f62e33c5229516710f7f078105c6cbb580a
```

The certificate digest `21569322706156fe...` matches the generated keystore
fingerprint above (`21:56:93:22:...` byte-wise) — the APK is signed with the
production keystore.

## 5. R8 minification keeps ML Kit + OcrHelper (release outputs)

- `app/build/outputs/mapping/release/seeds.txt`: ML Kit registrars kept
  (`VisionCommonRegistrar`, `TextRegistrar`,
  `dynamite.text.common.ModuleDescriptor`, `CommonComponentRegistrar`).
- `app/build/outputs/mapping/release/usage.txt`: `com.shrinkmedia.compressor.OcrHelper`
  fully referenced (not dead-stripped).
- `app/build/outputs/mapping/release/mapping.txt`: `OcrHelper` present.

## 6. Sideload install on API-36 hardware

```
$ adb install -r app-release.apk   ->  Success
$ <launch com.shrinkmedia.compressor> ->  app opens
```

PASS: the signed v0.3.0 APK installs and launches on the Xiaomi `25078RA3EA`
(API 36) device — the real-world sideload proof.
